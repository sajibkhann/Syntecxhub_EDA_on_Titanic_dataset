🚢 Syntecxhub EDA on Titanic Dataset

This repository contains a comprehensive Exploratory Data Analysis (EDA) on the famous Titanic dataset — one of the most widely used datasets in data science and machine learning for beginners and practitioners alike.

The analysis is performed using Python with popular data analysis and visualization libraries to uncover patterns, trends, and insights related to passenger survival rates. The goal is to understand how different factors such as gender, passenger class, age, fare, and family relationships influenced survival outcomes aboard the Titanic.

📁 Project Contents

- Titanic-Dataset.csv — Raw dataset containing passenger information (survival status and attributes)

- main.ipynb — Jupyter Notebook with:

  - Data loading and inspection

  - Data cleaning (handling missing values)

  - Exploratory visualizations using matplotlib and seaborn

  - Summary of key findings and insights

📊 Highlights

- Explore missing values and cleaning techniques

- Visualize relationships between features (e.g., Survival vs Gender, Passenger Class, Age Distribution)

- Draw meaningful conclusions about passenger survival patterns

- Great resource for anyone learning data analysis, EDA techniques, or Python for data science

🛠️ Tech Stack

Python

- Pandas, NumPy (data manipulation)

- Matplotlib, Seaborn (visualization)

- Jupyter Notebook (interactive analysis)
